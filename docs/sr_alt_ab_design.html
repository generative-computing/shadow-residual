SR shared LoRA-A: alternating A/B training, and one A for the whole model

Granite 4.2 3B (granite-4.2-3b-prerelease-r260622a), Shadow-Residual adapters, LoRA r 32, α 64 on q/o/gate/up/down/cross_stream. Four intrinsics: answerability (ans, acc), guardian_core (guard, acc), query_clarification (qc, overall acc), requirement_check (req, balanced acc). Study sr_alt_ab, 2026-11-22/23.

Summary. (1) At equal data (5K rows), a frozen random A shared by all four adapters beats vanilla LoRA on ans (+0.84) and guard (+0.45), CIs exclude 0, and ties on qc and req. (2) A second step that freezes those B's and jointly trains the shared A adds nothing (ans/guard/qc flat, req −1.6). (3) Training a shared A for the four vanilla B's recovers from a collapsed start (ans 4.4 → 83.9) but ends −2.0 points (mean) below vanilla; the training-free post-hoc compression with refit B (−0.14) is better. (4) One random A tensor for every site of every layer (32×8192, 262K values instead of 26.9M) matches vanilla: mean −0.14, ans +0.65 (significant).

4. Reading

  • Freezing A helps when data is limited. With full data, frozen random A ≈ vanilla (frzr +0.19 mean). At 5K it is ahead on the two large eval sets. This fits the A–B asymmetry literature (Zhu et al. 2024, LoRA-FA, FFA-LoRA): B does the task-specific work, and freezing A halves the trainable parameters and removes a source of overfitting.
  • The alternating A-step is not worth it. With B fixed, one epoch of joint shared-A training leaves the s1 adapters unchanged or slightly worse. The random A was already as good a basis as a jointly trained one for these B's.
  • Fitting a shared A to B's trained against other A's is hard by gradient descent. s3b starts from collapsed adapters and recovers most of the way in one epoch, but ends 2–5 points below vanilla on ans/guard/req. The closed-form route (post-hoc dw:32: shared A + least-squares refit of B, −0.14) keeps more because it moves B, not A.
  • One A for the whole model is enough. A single 32×8192 random matrix serves all 240 (layer, site) LoRA A's at no measurable cost (ans significantly better, guard/req equal, qc −1.8 within its noise). Each site still applies A to its own input, so the shrink FLOPs are unchanged; the saving is A storage/loading (26.9M → 262K values) and, for training, the guarantee that A carries no task or layer information.

5. Implementation

  • src/shadow_residual/training/train_shared_a_fixed_b.py: multi-task train.py with the tied A initialised from a bank (trainable) and each task's B copied from an existing adapter and frozen (patches multitask.setup_shared_a). Post-train check: saved B == source exactly, A identical across exports, A moved from init. --export-init-only writes the step-0 adapters. Test: tests/training/test_shared_a_fixed_b.py.
  • frozen_a.install_frozen_a(..., freeze=True): freeze=False only initialises A.
  • compress_a.structured_bank(..., whole_model=True) / python -m shadow_residual.training.compress_a --whole-model: the single-draw bank.
  • Jobs: scratch/altab/gen_yamls.py (prefix antonp-altab-), commit 5558a47 + working-tree overlay (code_v1, code_v2). Bootstrap: scratch/altab/code_v1/boot_altab.py.
